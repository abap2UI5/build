## Install

1. The namespace `/CA2UI5/` has to exist in the system (SE03, changeable, with a developer license) and a package of that namespace to pull into.
2. abapGit: New Online, this repository, branch `#ca2ui5#-cloud`, that package, Pull. The packages are named `<package>_01` .. `<package>_04` and below - abapGit's PREFIX folder logic.
3. Open the URL the HTTP service `/CA2UI5/UI5` shows in ADT (`/sap/bc/http/ca2ui5/ui5`).

Not part of this branch: the launchpad integration of abap2UI5's `cloud` branch
(IAM app, business catalog, the deployed Fiori app). Their names are tied to the
original installation; for a tile, create an IAM app for the HTTP service
`/CA2UI5/UI5` and assign it to a business catalog of yours in ADT.
