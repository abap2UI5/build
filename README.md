## Install

1. The namespace `/Z2UI5/` has to exist in the system (SE03, changeable, with a developer license) and a package of that namespace to pull into.
2. abapGit: New Online, this repository, branch `#z2ui5#-standard`, that package, Pull. The packages are named `<package>_01` .. `<package>_04` and below - abapGit's PREFIX folder logic.
3. SICF: activate /sap/bc/z2ui5/ui5 (below the namespace nodes /sap/bc/z2ui5, which the pull creates).
4. Open `/sap/bc/z2ui5/ui5`.
