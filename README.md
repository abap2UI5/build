## Install

1. The namespace `/KRO/` has to exist in the system (SE03, changeable, with a developer license) and a package of that namespace to pull into.
2. abapGit: New Online, this repository, branch `rename_kro`, that package, Pull. The packages are named `<package>_01` (backend, with `_01_00` .. `_01_99`) and `<package>_02` (frontend, with `_02_01`, `_02_02`) - abapGit's PREFIX folder logic.
3. SICF: activate /sap/bc/kro/ui5, /sap/bc/ui5_ui5/kro/ui5, /sap/bc/bsp/kro/ui5, (and the namespace nodes /sap/bc/kro, /sap/bc/ui5_ui5/kro, /sap/bc/bsp/kro).
4. Open `/sap/bc/ui5_ui5/kro/ui5/index.html`.
