## Install

1. Create a package to pull into.
2. abapGit: New Online, this repository, branch `zabap2ui5-standard`, that package, Pull. The packages are named `<package>_01` .. `<package>_04` and below - abapGit's PREFIX folder logic.
3. SICF: activate /sap/bc/zabap2ui5.
4. Open `/sap/bc/zabap2ui5`.
