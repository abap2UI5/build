## Install

1. The namespace `/KRO/` has to exist in the system (SE03, changeable, with a developer license) and a package of that namespace to pull into.
2. abapGit: New Online, this repository, branch `#kro#-standard`, that package, Pull. The packages are named `<package>_00` .. `<package>_03` and below - abapGit's PREFIX folder logic.
3. SICF: activate /sap/bc/kro/ui5 (below the namespace nodes /sap/bc/kro, which the pull creates).
4. Open `/sap/bc/kro/ui5`.
