## Install

1. Create a package to pull into.
2. abapGit: New Online, this repository, branch `zabap2ui5-cloud`, that package, Pull. The packages are named `<package>_01` .. `<package>_04` and below - abapGit's PREFIX folder logic.
3. Open the URL the HTTP service `ZABAP2UI5` shows in ADT (`/sap/bc/http/sap/zabap2ui5`).

Not part of this branch: the launchpad integration of abap2UI5's `cloud` branch
(IAM app, business catalog, the deployed Fiori app). Their names are tied to the
original installation; for a tile, create an IAM app for the HTTP service
`ZABAP2UI5` and assign it to a business catalog of yours in ADT.
